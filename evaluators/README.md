# Evaluators (reviewer reference copies)

Reference copies of the evaluator contract surface so reviewers can read the
evaluation logic without walking the package tree. CANONICAL SOURCE:
`src/agent_eval_harness/evaluators/` (importable as
`agent_eval_harness.evaluators`). These copies are refreshed by
`scripts/package_release.py` at build time — if they drift from src/, treat
src/ as the truth and re-run the packager. (The stale committed `source/`
tree that used to be referenced here was removed in this change; the release
zip layout is generated by package_release.py, never committed.)

- `base.py` — Evaluator protocol
- `deterministic_outcome.py` / `deterministic_tools.py` — deterministic checks
- `trajectory_behavior.py` — trajectory + behavioral evaluators
- `llm_judge.py` — rubric + live judge backends (versioned prompts in ../prompts/)
- `registry.py` — name -> factory registry (20 evaluators)
